JC Haus & Hof Service
A professional business website built to showcase home and property services with a clean, responsive design. The project highlights:

Service presentation: Clear sections for offerings and contact details.

User-friendly design: Mobile‑ready layout with intuitive navigation.

Scalable backend: Structured to support future integrations and updates.

This repository contains the source code and assets for maintaining and improving the website.
**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
